# Terraform Lab Desktop Design

[한국어](README.md) · [English](README.en.md)

## 목적

교육 가이드·내비게이션·터미널을 한 화면에 배치하는 데스크톱 UI 기준입니다.

## 기대 효과

- 학습 설명과 명령 실행 사이의 이동을 줄이고 진행 상태를 명확히 보여줍니다.

## 주요 기능과 구성

- 밝은 헤더·내비게이션, 중앙 학습 가이드, 짙은 터미널의 3열 구조
- 명령 복사·터미널 입력·검증·스킵과 다음 단계 이동
- 보라색 강조와 일관된 성공·잠금·스킵 상태

## 범위와 제약사항

개념 이미지입니다. 표시된 CLI 버전과 단계 수는 실제 커리큘럼의 기준이 아닙니다. 실행 버전은 런타임 설정과 과정 문서를 확인하세요. 모바일 전용 화면은 범위에 포함되지 않습니다.
