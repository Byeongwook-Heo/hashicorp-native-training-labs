# Terraform Lab 데스크톱 디자인 기준

기준 이미지: `terraform-lab-desktop-concept.png` (1586×992)

생성 프롬프트 요약: 1440×900 한국어 Terraform 교육랩, 상단 헤더, 밝은 7랩 사이드바와 진행률, 중앙 학습 가이드, 우측 graphite 터미널, Terraform purple `#7B42BC`, 성공·스킵 기반 잠금, 복사·터미널 입력, gradient·과도한 card·pill 없음.

구현 fidelity 기준:

1. 밝은 header와 3열 데스크톱 구조
2. 300px 내비게이션 sidebar와 원형 단계 상태
3. 중앙 설명·명령·복사·입력 동작
4. 우측 graphite terminal과 명확한 연결 상태
5. 보라색 계층, 성공·잠금·스킵 상태의 일관된 색상
6. 검증 성공 또는 스킵 전까지 다음 단계 잠금
7. 검증·스킵·다음 단계 action을 학습 흐름 안에서 항상 발견 가능

개념 이미지의 예전 CLI 버전 표시는 구현에서 보안·재현성 계약에 맞춘 Terraform 1.15.8로 교체합니다. 모바일 전용 변형은 현재 제품 범위가 아닙니다.
